# Вместе

Веб-приложение для совместного просмотра видео на YouTube. Создайте комнату, пригласите друзей по ссылке и смотрите видео с синхронным воспроизведением и общим чатом.

## Локальный запуск

Запустите Docker Desktop и выполните команду в корне проекта.

```sh
docker compose up -d --build
```

Откройте [http://localhost:8080](http://localhost:8080).
